# .github

Organization-level files for [core-keys](https://github.com/core-keys).

- `profile/README.md` — the landing page shown on the organization page.
- `brand/` — the logo assets and the script that generates them. See
  [brand/README.md](brand/README.md); the mark is derived from the device's own
  UI, so it is regenerated, not redrawn.
